# Glows & Grows (Basic)

For each response, write student-facing feedback in this shape:

- 2-3 glows: specific things that worked.
- 1-2 grows: specific things to improve.
- 2-3 strategy sentences for the next attempt.

Quote briefly from the response to justify the score when a short quotation is
safe and useful; otherwise paraphrase the evidence. Keep the tone supportive,
concrete, and concise. Do not instruct the agent to write a `COPY THIS:` block;
Canvas Expert appends that private correction block automatically when required.
