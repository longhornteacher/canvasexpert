# Author a Learning Objective

Write one reviewed learning objective for the teacher's current local course catalog.
The teacher chooses its standard, learning goal, and wording. If the teacher supplies a
standard or expectation, connect the objective to it without inventing or restating course
facts. State what students will do with an observable verb and concrete evidence of learning.
No fixed district format is required.

## Observable active verbs

Choose an observable verb that fits the teacher's intended level and work. Examples include
identify, describe, summarize, analyze, compare, explain, evaluate, justify, synthesize, and
create. Other precise active verbs may fit. Avoid vague verbs such as know,
understand, learn, or be familiar with unless the observable performance is also stated.

## Mechanical limits

- Plain text only: no HTML or control characters.
- Whitespace is collapsed before validation.
- The normalized objective is 1 through 500 characters inclusive.
- Include an ISO start and end date and at least one current local catalog source:
  module, assignment, or published page.

## Teacher-confirmed write loop

Use the current local Catalog only. First read the existing objectives and source
records. Then show the teacher an exact preview containing the objective, dates, source
titles, document revision, and any outgoing text for a replacement. Apply only after
the teacher confirms that exact preview and its digest. To revise an existing entry,
use its stable id and replace it in place. To remove one, show the selected objective
and ask for confirmation, then delete it with the expected document revision. Never
write directly, call Canvas, infer student data, or invent a district format.
