Writing Record - private longitudinal writing evidence

Use get_writing_history(pseudonym) when a teacher asks to inspect one
student's dated writing evidence. It is separate from Scoring Sessions and from
Writing Timeline. It does not score, coach, assign a tier, infer a trend,
recommend feedback, or decide whether an assignment meets a rubric.

What is stored

For every teacher-authorized acquisition, CanvasExpert retains the reliable
assignment context (date, prompt, and supplied scaffolds/source text when
available) and each acquired student's scrubbed text. It also retains stable
assignment/rep and submission IDs, timestamp, student word count, segment
origins/spans/method/confidence, scrub findings, and structural flags. Segment
attribution distinguishes assignment, scaffold, student, and quoted-source
text so later readers can accurately see what counts as student writing.

How work enters

A teacher selects one Canvas assignment in CanvasExpert's web UI or equivalent
local CLI. That action scopes one teacher-triggered acquisition; it is not a
persistent tracking or eligibility flag. Every acquired response is eligible:
there is no assignment-type, length, genre, or opt-in classifier. Typed text
comes from the local mirror. A DOCX upload may be read through the focused
teacher-triggered Canvas path; PDF, OCR, and other new attachment types are
not part of this tool. Re-ingesting a stable assignment/submission replaces
the current record read without creating a second current piece.

What the assistant receives

get_writing_history returns dated submissions in ascending order with
assignment context, IDs, timestamp, student word count, segment attribution
metadata, and flag codes. include_text=false is the default and omits student
prose plus flag detail that can quote it. include_text=true returns scrubbed
raw_text and text-bearing flag material, trimmed by max_text_chars. Prompt
text is teacher-authored context and remains available under the same trim.

Privacy

The private store is keyed by Canvas ID at rest, but only pseudonyms leave the
machine. Names, Canvas IDs, SIS IDs, private paths, and unscrubbed text are
never projected. The outbound safety scan runs over every exposed text field.
The evidence is pseudonymized and scrubbed, not anonymous; the teacher reviews
it before sending it to any external AI service.

Open boundaries

Rubric capture, delivered-feedback history, and automatic acquisition are not yet
implemented. Scoring Sessions use Canvas Live as the grading and feedback-review surface.
