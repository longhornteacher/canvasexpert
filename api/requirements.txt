# Web UI (api/webui/) — local server, profile storage, OS-keychain token storage.
# Upper bounds are deliberate; an unpinned `fastapi>=0.110` drifted the stack and broke
# things twice over. Two distinct breakages drive the caps below:
#   * Starlette 1.x removed the legacy TemplateResponse(name, context) signature (broke
#     every page) and swapped its TestClient from httpx to httpx2. We now use the
#     TemplateResponse(request, name, context) form and pin Starlette to the mature 0.x
#     line (standard httpx).
#   * FastAPI 0.124 changed two behaviors our tests rely on: include_router() became lazy
#     (routes no longer eagerly flattened into app.routes — breaks the route-contract
#     snapshot) and required Form(...) fields now reject "" with 422 before the handler
#     runs (breaks roster empty-field handling). So we cap FastAPI below 0.124.
# Starlette is pinned explicitly (matching FastAPI 0.123's own starlette<0.51 ceiling)
# even though FastAPI pulls it transitively. Tested on fastapi 0.123 / starlette 0.41 /
# uvicorn 0.49 / httpx 0.28: app renders + full api/tests suite green.
fastapi>=0.121,<0.124
starlette>=0.40,<0.51
uvicorn>=0.29,<1
jinja2>=3.1,<4
keyring>=24.0
python-multipart>=0.0.9
