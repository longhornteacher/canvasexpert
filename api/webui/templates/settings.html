Canvas account

Your Canvas API token gives Canvas Expert access to all your courses — paste it once here and you never need to touch it again. It's stored in your Windows Credential Manager (not in any file on disk).

In Canvas: Account → Settings → + New Access Token. Name it CanvasExpert – {{ computer_name }}, use no expiry unless your district requires one, copy it, and paste it here. Generate a fresh token on each computer; never reuse one or write it down. If a machine is lost, delete just that token from the same Canvas page.
